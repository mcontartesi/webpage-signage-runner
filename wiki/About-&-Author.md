## 🎯 Motivation & Design Philosophy

Commercial digital signage platforms are often burdened by costly recurring SaaS subscriptions, proprietary hardware lock-ins, bloated software, and poor support for multi-monitor video walls and custom authenticated REST feeds.

**Webpage Signage Runner** was built to provide an open-source, enterprise-grade, zero-cost alternative that is:
1. **Lightweight & Fast:** Minimal memory overhead with automated periodic cache purges to run indefinitely without slowdowns.
2. **Hardware Agnostic:** Runs on standard x86/x64 hardware across Windows and Linux.
3. **Resilient by Default:** Self-healing watchdog, automatic reconnection, and crash recovery.
4. **Developer & Sysadmin Friendly:** Comprehensive HTTP REST API, live screenshots, interactive Swagger UI, and JSON configuration.
