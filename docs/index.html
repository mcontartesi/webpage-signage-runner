This page is an interactive web demonstration and browser simulator of the First-Run Setup Wizard, Offline Fallback resilience system, and REST API of Webpage Signage Runner. Running in a browser, it does not control physical external monitors or OS hardware directly. For 24/7 production unattended digital signage with multi-monitor orchestration, download the compiled native desktop application for Windows or Linux.
